## 📁 **Структура бэкенда Board OCR**

```
board_ocr_backend/
├── 📁 app/                          # Основное приложение
│   ├── 🐍 __init__.py              # Делает папку Python пакетом
│   ├── 🚀 main.py                  # Основной файл FastAPI приложения
│   ├── 📊 schemas.py               # Pydantic схемы для валидации данных
│   ├── 🗃️ models.py                # Модели SQLAlchemy для базы данных
│   ├── ❌ exceptions.py            # Кастомные исключения и обработчики ошибок
│   └── 📁 utils/                   # Вспомогательные утилиты
│       ├── 🐍 __init__.py
│       ├── 📄 pdf_generator.py     # Генерация PDF файлов
│       └── 🔍 file_validator.py    # Валидация загружаемых файлов
├── 📁 uploads/                     # Временное хранение загруженных изображений
├── 📁 outputs/                     # Сгенерированные PDF файлы
├── 🐍 run.py                       # Скрипт запуска сервера
├── 🧪 test_api.py                  # Тесты API (создашь позже)
├── 📝 requirements.txt             # Зависимости проекта
└── 📖 README.md                    # Документация проекта
```

## 📋 **Подробное описание каждого файла:**

### **📁 app/__init__.py**
```python
# Пустой файл, делает папку app Python пакетом
# Позволяет делать импорты like: from app.main import app
```

### **🚀 app/main.py**
**Отвечает за:** Основную логику API, эндпоинты, обработку запросов
**Содержит:**
- Создание FastAPI приложения
- Эндпоинты: `/`, `/api/upload-images`, `/api/generate-pdf`, `/api/download-pdf`
- Обработку загрузки файлов
- Интеграцию с ML-модулем (заглушка)
- Логирование и обработку ошибок

### **📊 app/schemas.py**
**Отвечает за:** Валидацию входных и выходных данных
**Содержит:**
- Pydantic модели для запросов/ответов
- Валидацию типов данных, форматов
- Модели: `MultiImageOCRRequest`, `OCRResponse`, `PDFRequest`, `PDFResponse`

### **🗃️ app/models.py**
**Отвечает за:** Структуру базы данных
**Содержит:**
- SQLAlchemy модели: `ProcessingRequest`, `ProcessedImage`, `GeneratedPDF`
- Настройку подключения к БД (SQLite)
- Функции для работы с БД: `get_db()`, `create_tables()`

### **❌ app/exceptions.py**
**Отвечает за:** Обработку ошибок и исключений
**Содержит:**
- Кастомные исключения: `BoardOCRException`, `FileValidationError`
- Глобальные обработчики ошибок
- Форматы ответов при ошибках

### **📄 app/utils/pdf_generator.py**
**Отвечает за:** Создание PDF файлов из текста
**Содержит:**
- Функцию `create_pdf_from_multiple_images()`
- Настройку стилей PDF (шрифты, отступы, разметка)
- Генерацию контента из распознанного текста

### **🔍 app/utils/file_validator.py**
**Отвечает за:** Проверку загружаемых файлов
**Содержит:**
- Валидацию форматов (JPEG, PNG, WebP)
- Проверку размеров файлов (макс. 10MB)
- Проверку количества файлов (макс. 10)
- Определение MIME-типов

### **🐍 run.py**
**Отвечает за:** Запуск сервера в development режиме
**Содержит:**
- Создание необходимых директорий
- Запуск Uvicorn сервера
- Настройку autoreload при изменениях

### **📝 requirements.txt**
**Отвечает за:** Управление зависимостями проекта
**Содержит список всех необходимых пакетов:**
```
fastapi==0.104.1
uvicorn==0.24.0

```

## 🎯 **Ключевые особенности:**

- **Модульность** - каждый файл отвечает за свою зону ответственности
- **Валидация** - данные проверяются на каждом этапе
- **Обработка ошибок** - понятные сообщения при проблемах
- **Масштабируемость** - легко добавлять новые функции
